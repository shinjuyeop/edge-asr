# M3 공개 VAD 자료 준비 — 2026-10-29

**실제 공개 음성과 시간 라벨을 확보하고 검수용 WAV 98개를 준비했다.** Host와 RP5의 자료 일치와 단위 테스트를 확인했다. 사람 검수·정답 확정·새 ASR/VAD 추론은 아직 수행하지 않았으며 M3 정확도 개선이나 Hybrid 준비 완료를 뜻하지 않는다.

## 확보·선정 결과

[Seoul Corpus](https://www.openslr.org/113/)는 CC BY-NC 2.0이다. 사용자는 개인·학술 연구용이라고 확인했다. 안내와 시간 라벨 240개에 이어 실제 FLAC 240개를 다운로드했고, gzip 및 ZIP 전체 멤버 CRC 검사를 통과했다. 로컬 SHA-256을 기록했으며 공식 체크섬과 대조했다는 뜻은 아니다. 배포된 TextGrid 240개 모두 파싱했고 격리된 파일은 없었다.

[RIRS_NOISES](https://www.openslr.org/28/)의 pointsource 하위 자료에서 미리 고른 WAV 5개를 재사용했다. 상위 리소스의 Apache 2.0 표기와 하위 LICENSE의 Public Domain 설명을 구분해 기록했다. 이들의 말소리 포함 여부는 아직 청취 검수하지 않았다.

| 검수 후보 | 수 | 라벨상의 발화 길이 | 문맥을 포함한 WAV 합계 |
| --- | ---: | --- | ---: |
| 짧은 발화 | 80 | 0.108~0.490초 | 107.779초 |
| 긴 발화 | 13 | 8.065~10.217초 | 130.637초 |
| 잡음 후보 | 5 | 음성 여부 미확정 | 150.162초 |
| 전체 | **98** | — | **388.578초** |

40명 화자에 대해 짧은 발화 최대 2개·긴 발화 최대 1개를 파일명/발화 순서로 선택했다. 사전 후보 범위는 각각 80~500ms, 8~20초였지만 실제 긴 후보는 13명에서만 나왔다. 모델 결과를 보고 표본이나 임계값을 선택하지 않았다. 모든 특수 태그를 감사 목록에 남겼다. 후보 전사는 `utt.ortho.`에서 가져왔으며 실제 평가 정답으로 확정하지 않았다.

후보와 관련된 원본 FLAC 47개를 별도로 보존했다. 전체 음원을 Host ffmpeg로 16kHz·모노·PCM16으로 변환한 뒤 같은 샘플 격자에서 앞뒤 최대 0.5초 문맥을 포함해 잘랐다. WAV 98개, 원본 FLAC 47개, 검수 목록·청취 페이지 2개 등 **147개 파일의 해시**를 기록했다. 영수증 자체는 별도 해시로 대조했다.

## 도구·검증 범위

구현 커밋은 `db070df6099acafbe64e2a8e66c9eae0e4105e8f`다. `src/edge_asr/textgrid.py`, `scripts/prepare_public_vad_review.py`, `scripts/materialize_public_vad_review.py` 및 단위 테스트 2개 파일을 추가했다. 기존 ASR 어댑터·평가기·전처리 정책은 바꾸지 않았다. 한국어 절차와 원본 보존·라이선스 안내도 추가했다.

- Host 전체 **152개 통과, 7.738초**. 합성 44.1kHz 자료의 실제 ffmpeg 변환·샘플 단위 절취, TextGrid 인코딩·중복 tier·잘못된 시간, 원본 보존과 미검수 평가 거부를 검사했다.
- RP5 전체 **152개 통과, 13.715초**. 모델을 쓰지 않는 단위 테스트이며 실제 ASR/VAD 추론 성공과 구분한다.
- Host에서 라벨 감사·후보 선정을 다시 수행해 두 JSONL의 SHA-256이 동일함을 확인했다.
- RP5 새 경로에 패킷을 복사한 뒤 147개 파일과 영수증 해시를 확인하고 WAV 98개를 실제로 읽어 형식·길이·해시를 확인했다.
- 동기화 전후 `.venv`, `models`, `data`, `results`, `experiments` 범위의 기존 파일 **3,819개 내용/파일 링크가 동일**했다. 별도 `data/README.md` 1개 변경은 이번 Git 문서 수정과 일치했다. Python 버전과 설치 패키지 목록도 동일했다. 이전 백업 폴더 전체까지 검사했다는 뜻은 아니다.
- 미검수 목록은 `reference=null`이므로 기존 평가기의 입력 검사에서 거부됐다. 음성 구간·음성 기대값도 null이다. 새 CER·RTF·실제 음성 끝 지연은 측정하지 않았다.

## 위치와 다음 작업

Host 원본은 `data/sources/seoul-corpus-20261029-01/`, `data/sources/rirs-noises-20261029-01/`에 있다. 원래 안내/라벨 영수증은 그대로 두고 추가 음성 확보를 `audio-acquisition.json`에 기록했다. 후보/감사 기록은 `data/review/m3-public-vad-20261029-01/` 및 동일 출력 재현 검사 `-02/`에 있다.

Host와 RP5 양쪽의 **`data/review/m3-public-vad-audio-20261029-01/index.html`**에서 검수 음원을 열 수 있다. 같은 폴더의 `review.jsonl`은 정답 미확정 목록이다. 새 전송·환경 보존·테스트 원시는 `results/preflight/m3-public-vad-data-20261029-01/`에 보존한다. 음성·전사·원시 기록은 Git에서 제외했다.

다음에는 실제 청취/파형과 배포 라벨을 대조해 말소리·면접자 발화·웃음·잡음 및 정확한 음성 시작/끝을 확정한다. 검수자·버전·대상 WAV 해시와 제외 사유를 별도 결정 파일에 기록하고, 개발/보류 화자를 **성능 측정 전에** 고정한다. 그 뒤 구간 정답 기반 채점기를 연결해 같은 원음/RMS 정책으로 RP5에서 재평가한다. 아직 이 결정 파일 내보내기/채점 연결은 구현하지 않았다.

이번 98개는 개발용 검수 후보이며 최종 독립 평가 세트가 아니다. 모델 학습 중복도 미확인이다. 기존 5/9 누락·4/6 잡음 오탐, native 활성 30초 제한, Zipformer 2T의 냉각 중단은 해결됐다고 보지 않는다. 고부하 동시 ASR 실행은 재개하지 않았다.
