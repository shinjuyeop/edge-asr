# 코드·문서 구조 정리 검증 — 2026-10-29

**실행 도구 23개를 패키지의 역할별 영역으로 옮기고, 공통 기능과 문서 탐색을 정리했다.** Host/RP5 각 169개 테스트, 기존 ASR 50건·VAD 160건 재채점, 실제 RP5 VAD 4회 출력 계약 검증을 통과했다. 측정 수치·정규화 정책·VAD 정책 승인 상태는 변경하지 않았다. 구현 커밋은 `5188625`다.

## 변경한 구조

| 영역 | 변경 |
| --- | --- |
| 실행 코드 | 기존 `scripts/*.py` 구현 23개를 `src/edge_asr/tools/data`, `probes`, `reports`, `maintenance`로 이동. `edge-asr tools`의 고정 명령 24개로 실행 |
| 루트 scripts | 추적 파일 28개에서 공통 CLI·M1 반복 호환 진입점·선택 배포 스크립트 3개로 정리 |
| 공통 산출물 | `artifacts.py`로 SHA-256·원자적 JSON·JSONL 읽기/스트리밍 쓰기를 합침. 비유한 JSON 거부와 실패 시 기존 파일 보존 |
| 공통 자원/환경 | `resources.py`로 CPU/RSS 표본을 분리하고 환경 기록을 `runtime.py`로 이동. 자료/집계 도구가 평가 실행기에 의존하지 않음 |
| VAD 계약 | `vad.py`의 설정/factory, `segmentation.validate_capture`, `vad_annotations.select_development`로 실행/집계 간 역방향 import 제거 |

| 문서 | `docs/guides`, `reference`, `research`, `archive`로 구분. README를 현재 사용법 중심으로 줄이고 문서·결과 색인 및 현재 상태/다음 과제 추가 |
| 유지 검사 | Ruff 설정과 Host용 dev extra 추가. 동적 파일 로더를 패키지 import로 바꾸고 명령/의존 방향/링크/원자적 저장 회귀 검사 추가 |

기존 공통 평가 CLI와 `scripts/edge_asr.py`, `scripts/benchmark_zipformer.py`는 유지한다. 나머지 과거 scripts 파일 직접 호출은 [명령 이행표](../../docs/reference/tooling.md)로 변환한다. 이전 모듈의 공통 helper import 경로도 같은 함수를 제공하는 호환 경로로 남겼다. 새 환경/가중치를 추가하거나 RP5 패키지를 설치하지 않았다.

코드 포맷을 정리하고 미사용 import를 제거했다. JSONL 저장은 전체 직렬화 문자열을 한 번에 만들지 않고 행마다 쓴다. 기존 M1 반복 도구의 기본 자산 루트는 패키지 설치 위치 대신 작업 폴더를 사용한다. 추론 알고리즘·계측 범위의 의미·실험 조건을 최적화해서 성능이 개선됐다고 주장하지 않는다.

## 검증 결과

- **Host 169개 / RP5 169개 테스트 통과.** 신규 검사는 24개 도구의 외부 작업 폴더 도움말 실행, 선택 런타임 없는 import, 코어/집계 의존 방향, 문서 링크, 실패 시 원자적 JSON 보존을 확인한다.
- Ruff 0.14.14의 `check`, `format --check` 통과. RP5에 Ruff를 설치하지 않았다.
- wheel 빌드 완료. 포함된 Python 소스가 현재 소스와 바이트 일치하며, wheel에서 명령 모듈 24개를 실제 import해 NumPy/sherpa/평가 실행기를 불필요하게 불러오지 않는지 확인했다.
- 새 도구로 공개 주석 98개를 다시 생성해 기존 `annotations.jsonl`과 출처 JSON이 바이트 일치했다. 기존 VAD 160건의 원시 재채점과 ASR 50건의 집계 결과도 동일했다.
- **실제 RP5 VAD 4회**: 기존 개발 초단문/장문 각 1개 × 원음/RMS. 전처리 PCM, 반환 구간·payload 해시, 채점 결과가 과거 기록과 같았다. 기존 열/시간/4GiB 제한 아래 출력 계약을 확인한 소규모 회귀 검사이며 새 정확도/속도 비교가 아니다. ASR 모델을 새로 추론한 검사는 아니다.
- 원본 M1 프로브와 참고 디코더 SHA 검증 통과. M1 탐색 TOML도 이동 전과 바이트가 같다. 기존 요약 JSON은 그대로이고 과거 Markdown 보고서는 상대 링크만 갱신했으며 측정 내용/수치는 유지했다.
- RP5 기존 `.venv`, `models`, `data`, `results`, `experiments`의 **비 Markdown 파일 3,917개 내용/링크 및 Python·패키지 목록이 동일**했다. Markdown은 요청한 문서 구조 정리 범위이며 링크/안내를 갱신했다. 기존 원시·모델·오디오는 삭제하지 않았다.

검증 원시는 양쪽 `results/maintenance/refactor-20261029-01/`에 보존하며 Git에서 제외한다. 구조 정리 커밋의 변경 파일 목록, 테스트 시간·증거 해시·실제 VAD 환경과 제한 결과는 [기계 판독 기록](refactor-20261029.json)에 있다.
