## 조건과 확인한 범위

소스 `79d447a`. Host main push→RP5 동기화/테스트→새 ID `m31-online-vad-20261103-01` 순서로 실행했다. 기존 모델·원음·정답·TOML·환경은 유지하고 유효 스레드만 Zip1T/Sense2T로 기록했다. Sense는 INT8·ko·ITN false·기존 태그 분리, 공통 정규화는 `ko_cer_v1`이다. Zip 기존 INT8 encoder/joiner·decoder·tail0.66초는 Refine에 적용하지 않았다.

온라인 VAD는 기존 k2 Silero SHA·Python ORT1.31.1·1T, 기존 임계값/상태/상한5초다. ASR의 sherpa/core2.0.1 네이티브 ORT1.28.2와 구분했다. 같은 PID에서 Zip+VAD+분배/계측, 별도 spawn PID에서 Sense를 실행했다. 내부 VAD 파형 축적0·원본당 reset1회·hard_limit 중 reset0회를 확인했다.

## CPU·메모리·VAD 비용·열

CPU는1코어=100%이며 입력 대기를 포함한 같은 인접 표본의 main+Refine PID 합이다. VAD 조건의 main에는 Zip/VAD/분배/계측이 공존한다. 독립 입력 PID는 제외해 별도 보존했다. RSS는 같은 시각 모델 PID 합의 관측 최대이며 공유 페이지 중복 가능성이 있어 시스템 RAM/PSS 총량과 다르다.

입장≤53°C 3표본, 기존 `operational`/600초 timeout/4GiB 주소 공간/코어 덤프 제한과 main/Refine 자식 실제 제한을 확인했다. 최고65°C, 현재 제한·새 제한 이력·필수 계측 결측은 표본상0이며 기존 `0xE` 이력은 구분했다. 모든 `control_valid`는 false다. 팬·클럭·전압·기본 펌웨어 보호는 변경하지 않았고, 고정 클럭 비교나 장시간 냉각 보증으로 부르지 않는다. 과거 고부하85.9°C/스로틀링 기록도 유지한다.

재조립 버퍼는 KSS 최대3,184프레임/합성1,600프레임, PCM ring은 최대99,200프레임이었다. 후속 후보는 실제 tail이 짧아 이번 native payload 관측 최대가80,000프레임이었고, 허용 상한83,200프레임을 실제 사용했다고 표시하지 않는다. 파형 축적0은 VAD 내부 상태에 관한 것이며 WAV 전체를 읽는 계측 도구의 무제한 입력 메모리 보증은 아니다.
