# WAV 자막 단계의 저장소 정리·회귀 검증

2026-11-03. 기준 `e6f1449` → 실제 검증 소스 `b4432e3`. Host에서 정리 후 main에 push하고 RP5를 fast-forward했다. 모델·Python 환경·기존 측정 정책은 변경하지 않았다. 마이크가 없는 현재 단계에서 WAV 자막 MVP까지의 작업을 정리했다.

## 정리한 구조

| 변경 | 이유와 범위 |
| --- | --- |
| `concurrent_probe.py`를 `realtime/replay.py`, `realtime/refine.py`로 분리 | 입력 분배와 Offline 자식 프로세스의 책임을 나눔. 기존 100ms 입력·유한 큐·워밍업 유지 |
| `online_vad.py`, `captions.py` → `realtime/vad.py`, `realtime/captions.py` | 현재 WAV 실시간 경로를 한 폴더에서 찾도록 정리 |
| `ReturningRefineChannel`을 `RefineChannel`로 통합 | 실험용 병합 모듈을 거치지 않고 결과 수신 callback을 연결. 큐/EOF/오류/종료 코드는 한곳에서 관리 |
| JSONL 쓰기 → `artifacts`, PCM 해시 → `dataset` | 같은 직렬화·flush·little-endian 해시 규칙 재사용 |
| 다중 PID 계측 → `resources`, 외부 제한 확인 → `runtime` | 동시 실행 프로브에 들어 있던 공통 기능을 실제 책임에 맞게 이동 |
| 자막 집계 → `tools/reports/captions.py` | `tools/live.py`는 실행을 조합하고, 저장 이벤트 검증은 모델 없이 재사용 |
| 자막의 누적 `events` 리스트 → 이벤트 카운터 | JSONL과 메모리에 긴 부분 전사를 이중 누적하던 비용 제거. 기록·순서·원문은 유지 |
| README·status·guides·reference·폴더 안내 정리 | 현재 사용법, 공통 지표 계약, 과거 수치를 중복 기재하던 부분 통합 |
| `docs/research/README.md`, `docs/archive/command_migration.md` 추가 | 과거 계획/결정 근거의 색인과 옛 명령 이행표를 현재 안내에서 분리 |

내부 import 경로는 갱신했으며 과거 Python 내부 경로에 별도 shim은 만들지 않았다. 공개 CLI·TOML·결과 스키마·`ko_cer_v1`·모델 어댑터·CER/RTF 정의는 유지했다. 이전 소스는 당시 커밋으로 재현한다. 실험용 병합 코드와 과거 연구 문서는 검증 근거이므로 보존했다. 전체 변경 파일은 [기계 판독 요약](refactor-20261103.json)의 `changes`에 있다.

## RP5 실제 동작 회귀

기존 공식 `0.wav` **3.5265초·단일 샘플 1회**를 `live`로 실행했다. 새 경로는 `results/live/refactor-20261103-01/`이다. 기존 Zip1T + Sense2T + Silero VAD1T·원음·vad0·operational 열 정책을 사용했다.

- 실제 Zip 부분/최종 전사·Refine 원문·구간 좌표·PCM 해시·설정·모델·런타임은 이전 M3-6 smoke와 일치했다.
- 표시 이벤트 9개, Zip 최종 1개, Refine 후보 1개. 입력/Refine 드롭 0, 종료 Refine 백로그 0초, 자동 교체 0.
- 관측 최고 온도 61.7°C, 현재 제한 0. 기존 이력 `0xE`는 전후 동일했다. 정상 종료 후 Refine 자식을 회수했다.
- 원시 기록과 stdout 이벤트를 Host에서 다시 대조했다. 정답 없는 WAV 실행이므로 CER는 null이다. 성능 순위·향상률을 검증하는 실험이 아니다.

## 보존·결과 회수

RP5에서 기존 `.venv`, `models`, `data`, `results`, `experiments`의 비Markdown 파일 **5,613개**를 전후 해시 대조했다. 변경/누락 0, Python·패키지 및 부팅/CPU/열 설정도 동일했다. Git 추적 모델 설정·기존 보고서 본문·원본 실험 파일은 변경하지 않았다. 새 보고서와 색인은 추가/갱신했다.

RP5의 새 raw/검증 파일 32개(1,041,424bytes)를 Host에 회수하여 SHA-256 전부 일치를 확인했다. 원시는 Git 제외 `results/live/`, `results/maintenance/refactor-20261103-01/`에 보존했다. 이번 요약만 버전 관리하며 과거 수치를 소급 수정하지 않았다.

## 남은 범위

자막 이중 누적은 제거했지만 메모리 절감량·처리 성능 향상률을 측정하지 않았다. 새 장시간 부하·마이크 입력·화면 렌더링·SSH 도착 지연도 이번 검사에 포함하지 않는다. 자동 교체는 계속 보류하며 다음 사용자 작업은 마이크가 준비된 뒤 실제 캡처를 연결하는 것이다. [현재 상태](../../docs/status.md), [WAV 자막 실행](../../docs/guides/live_captions.md), [구조와 확장 경계](../../docs/reference/architecture.md)를 기준으로 개발을 이어간다.
