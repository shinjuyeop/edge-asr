# Q8 가변 갱신의 부분 음성 창 캐시 — 2026-11-19

현재 Q8·headroom 정책에서 기존0.99초 독립 음성 창/embedding·음성 KV 재사용을 검증했다. 고정 요청 진단 후 같은 긴 음원12개를 RP5에서1배속으로 비교했다. 최종233구간의 PCM·전사·토큰과 CER **12.03%(384/3,192자)**를 유지했고 부분/확정 실패·입력 드롭은 모두0이다. [전체 수치·명령·해시](q8-cache-headroom-20261119.json).

## 현재 요청에서 재사용할 수 있었던 범위

직전 `decoder-headroom-20261118-01`의 Q8 부분180요청·누적289.224초 PCM을 조사했다. 같은 구간에서 성공한 요청의 완료 창이 다음 부분 요청에 남는다고 가정하면1.99초 창은 재사용 기회가0이었다.0.99초는24요청·23.76초(8.22%)였다. 이는 해당 요청열의 기회 분석이며 실제 절감 시간이나 새 실행의 요청 횟수를 예측한 값이 아니다. 확정에는 항상 전체 음성을 다시 계산한다.

따라서 이전 Q4·1.99초·요청 증가 실험을 그대로 반복하지 않았다. 기존0.99초 지원 경로를 Q8·현재 headroom에 적용하고, 호출을 더 자주 허용하는 정책 변경은 하지 않았다. 창별 정규화·padding·attention 문맥이 달라지는 경로이므로 원래 encoder의 수치 동등 증분 실행을 뜻하지 않는다.
