# 같은 GGUF 빌드에서 긴 음원의 확정 PCM 233구간 전체 대조

RP5에서 동일한 233개 입력을 두 번 전사했다. Q4_0 텍스트·출력층은 Q8_0보다 전체 호출 시간 합계가 **22.0% 짧았고**, 최종 CER는 **15.73%(502/3,192자)**로 Q8의 **12.03%(384/3,192자)**보다 3.70%p 높았다. 각 모델의 원시 출력과 생성 토큰열은 이전 1배속 스트리밍 확정 기록과 233/233개씩 일치했다. 이 입력에서는 bridge·음성 encoder·스레드·분할·KV 재사용 조건을 맞춘 뒤에도 decoder 가중치 구성에 따른 정확도 차이가 남았다. Q4가 더 낸 오류 118자는 자연발화 79자, 낭독 39자다. 두 자료에서 치환은 Q4가 86자, 삭제는 19자, 삽입은 13자 더 많았다. 두 자료의 CER는 각자 전체 정답과 구간순 확정 전사를 연결해 산출했고, 전체 CER는 오류 수와 정답 글자 수를 합산했다. 호출 예외의 부분 생성 원문은 채점 대상 가설에서 제외하고 그 구간의 정답은 분모에 남겼다. 공식 정규화는 `ko_cer_v1`이다.

- Q4는 233회 중 문자열을 232회 반환했다. 6개는 빈 문자열이었다. 자연발화 19·62·64·74번(56·56·88·344ms)과 낭독 36·63번(472·120ms) 모두 생성 토큰 0개에서 EOG로 끝났다. 자연발화 166번(680ms)은 반복 생성 64토큰 뒤 예외로 끝났다. 스트리밍의 비어 있지 않은 반환 조건을 만족한 구간은 226개다.
- Q8은 233회 모두 비어 있지 않은 문자열을 반환했다. 자연발화 74번과 낭독 36번은 마침표 하나로, 정규화 후 문자가 남은 구간은 231개다.
- 같은 모델의 233개 원시 문자열·토큰 ID·채점용 전사와 스트리밍 반환 조건의 판정이 과거와 각각 일치했다. 따라서 앞서 분석한 자연발화 내부 단어의 오류 차이 49자와 낭독 숫자 표기 진단의 차이 17자는 이번 전사에도 그대로 적용된다. 단어 시각은 배포 라벨, 숫자 치환은 제한된 사례의 사후 진단이다. [위치별 오류와 동일 전사 대조](longform-diagnosis-20261118.md)

토큰 decode 합계는 Q8 183.34초, Q4 108.12초로 75.22초 줄었다. 전체 호출에서 절약한 94.51초의 약 80%다. 음성 encoder 합계는 Q8 132.64초, Q4 136.02초였다. 양쪽 모두 이번 연속 호출에서 최고 87°C와 성능 제한이 관측됐다. native 단계의 열은 해당 단계 시간만 합산한다. CPU는 호출 내부 프로세스 CPU초 합을 (호출 경과초 합×4)로 나눈 값이다. RSS는 호출 중 주 프로세스 표본 최댓값이다. 온도와 현재 제한 시간은 각 실행의 외부 감시 표본을 사용했다. 약 1초 간격에서 직전 상태 값을 적분한 근사치이며 주소 공간 제한 4GiB, 기존 냉각과 펌웨어 열 보호, 시작 허용 온도 60°C를 유지했다. 각 자료×모델은 한 번 실행했으므로 시간·발열 차이에는 실행 순서와 장비 상태 영향이 남는다.

## 실험 범위와 후속 판단

실제 추론 소스는 `8129346`, 실행 ID는 `decoder-pair-full-20261118-01`이다. 기존 `benchmark-qwen3 --protocol reproduction --repetitions 1`을 `thermal-run`에서 실행했다. 원래 순서의 자연발화 167개와 낭독 66개를 각각 Q8→Q4, Q4→Q8 순서로 처리했다. 각 조합은 별도 프로세스에서 모델을 한 번 로드했고 추가 워밍업을 생략했다. 두 모델에 같은 KleidiAI OFF bridge, Q8 음성 encoder, 한국어 greedy, 생성 2스레드·음성/prefill 3스레드, 문맥 512·최대 출력 128을 적용했다. 텍스트 접두부 KV는 두 모델 모두 껐으며 466회 모두 재사용 0토큰이었다. Q4와 Q8의 차이는 텍스트 decoder 및 출력층 가중치 구성 전체에 대한 결과다. [파일럿 및 PCM 준비](decoder-pair-pilot-20261118.md)

네 조합 모두 전체 ID·순서·프레임·PCM 해시·설정과 열/주소 공간 검사 기록을 확인했다. 자연발화 Q4 worker는 모델 예외를 포함한 완료로 기록됐다. 각 실행의 호출 기록과 prediction을 대조했고, 원본 manifest를 사용해 연결 CER를 독립 편집거리로 검산했다. Host와 RP5의 원시 48개 파일 SHA-256이 일치했다. 기존 데이터 분할·소프트웨어의 변경이나 새 모델 변환은 없었다.

정확도를 우선하는 최종 자막에는 Q8을 유지한다. 빠른 Q4 계열의 정확도를 더 조사할 때는 **기존 Q4_0 본체·Q6_K 출력층**을 같은 233개·같은 bridge에서 한 조건만 추가하는 것이 다음 대조다. Host에서 두 Q4 GGUF의 이름·형상·타입·텐서 바이트 해시를 대조했으며 311개 중 310개는 같고 `output.weight`만 Q6_K와 Q4_0로 달랐다. 두 Q4 출력층은 과거 6개 연속 입력에서 58/280자·59/280자 오류였고, 이번 긴 입력에서 출력층의 기여분은 아직 미측정이다. [기존 출력층 선별](decoder-q4-20261117.md)
