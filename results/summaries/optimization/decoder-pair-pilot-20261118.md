## 조건과 검증

소스 `ac4cec7`, 실제 실행 ID `decoder-pair-pilot-20261118-FWwfDv`다. 준비 ID는 `decoder-paired-20261118-01`이다. 기존 긴 음원 WAV에서 자연발화 167개·낭독 66개를 원래 좌표로 잘랐다. 디스크에서 다시 읽어 233개 모두 두 모델의 과거 float32 입력 SHA-256과 일치함을 확인했다. 그중 자연발화 12·19·92·154번과 낭독 17·26·28·36번을 고정했다. Q4 우세, Q8 우세, 공통 오답, 짧은 잔여 실패가 포함된 목적 표본이다.

같은 기존 `decoder-q4-20261117-02/off/bridge`(KleidiAI OFF)와 같은 Q8 음성 encoder, 한국어 greedy, 생성 2스레드·음성/prefill 3스레드, 문맥 512·출력 상한 128을 사용했다. Q4는 기존 `Q4_0-HEAD-Q4_0`, Q8은 기존 Q8_0 파일이다. 짧은 실패 뒤에도 다음 호출의 KV 출발 조건을 같게 하려고 고정 텍스트 접두부 캐시를 양쪽 모두 껐다. 16호출 모두 캐시 적중과 재사용 토큰이 0이었다. Host·RP5 모델 자산/공유 런타임 해시와 24개 원시 결과 파일을 대조했다.

기존 `tools benchmark-qwen3 --protocol reproduction --repetitions 1`로 Q8→Q4 순서로 각 8회 실행했다. 같은 냉각에서 시작 허용 온도 60°C, 기존 `operational` 정책, 4GiB 제한을 적용했다. 두 실행 모두 운영 검사를 통과했다. 별도 워밍업 없이 모델별 첫 호출을 포함하므로 속도 비교용 표본으로 사용하지 않는다. 실제 1배속 자막 지연과 장시간 열 부하는 이 파일럿에서 측정하지 않았다.

## 전체 대조의 채점

다음은 준비된 233개를 모델별로 전사해 같은 자료 안에서 시간순으로 연결하는 단계다. 원본 manifest의 자연발화 2,129자와 낭독 1,063자를 각각 분모로 사용하고, 빈 출력은 정답 분모에 남긴다. 구간별 독립 정답을 만들지 않는다. 호출 예외·빈 문자열·구두점만 반환한 경우를 분리해 비교한다. 이번 파일럿에서 전체 CER는 미측정이다.
