# M3 새 열 정책 구현·실측: 75°C 경고 / 80°C 중단

2026-11-02. **사용자가 승인한 새 열 정책의 구현과 RP5 실제 작동을 검증했다.** Zipformer 2T는 75°C 경고 후에도 실행됐고 첫 80°C 이상 표본인 **80.95°C에서 중단**됐다. 정책 구현 검증과 해당 구성의 장시간 냉각 합격을 구분한다. 계획한 480초 연속 부하는 미완료다. [상세 JSON·원시 해시](m3-thermal80-20261102.json).

## 바꾼 것과 유지한 것

소스 `dfbd306`. `thermal-run --temperature-policy warn75-stop80`만 새 조건을 사용한다. 과거 재현용 기본값 `legacy75`와 `thermal.rejection()` 기본 75°C는 유지했다. 새 정책은 75°C 이상을 경고로 기록하고 80°C 이상·현재 제한·새 제한 이력·필수 계측 누락에서 중단한다. 자식 종료 직후 표본도 검사한다. 알 수 없는 정책은 실행 전에 거부한다.

새 폴링 대기는 0.25초로 줄였다. 실제 표본 간격에는 조회 비용이 더해지며, 온도가 절대로 80°C를 넘지 않는다는 보증이 아니다. 팬 곡선·PWM·클럭·governor·전압·모델·Python 환경을 변경하지 않았다. 시작 조건은 53°C 이하 3회 연속, timeout 600초·주소 공간 4GiB·core 0과 실제 PID 제한 확인을 유지했다.

기존 Zipformer 2T·tail padding 0.66초·KSS 개발 50개 순서·워밍업 3회·최대 480초를 사용했다. 과거 75°C 검사와 설정 값/설정 SHA/manifest SHA/가중치 4개 SHA가 같았다. 다만 온도 한계와 폴링 빈도가 달라 같은 통제 조건의 속도 비교로 쓰지 않는다. 과거 결과의 실패 판정을 새 기준으로 고치지 않았다.

## 실제 작동과 결과

| 관측 | 온도 | 팬 | 감시 시작 전 표본 기준 경과 |
| --- | --- | --- | --- |
| 시작 전 | 52.35°C | 2,953RPM | 0초 |
| 첫 75°C 이상 경고 | 75.45°C | 6,741RPM | 약 16.930초 |
| 첫 80°C 이상 중단 표본 | **80.95°C** | **9,171RPM** | **약 33.337초** |
| 중단 직후 별도 표본 | 78.20°C | 9,171RPM | 약 33.350초 |

첫 경고 뒤 약 **16.408초** 더 관측했다. 75°C에서 종료하지 않고 새 80°C 규칙이 작동했다. 위 시간은 로딩·워밍업 등을 포함한 감시 구간의 실제 경과 시간이며 오디오 길이나 순수 추론 시간과 다르다. 표본 사이 정확한 임계값 통과 순간은 미확인이다.

열 표본은 131개, 75°C 이상 monitor/after 경고는 **63개**였다. 경고 표본 수는 독립 실험 횟수나 오류 수가 아니다. 경고 로그 순서·조건·첫 표본·영수증의 수를 모두 원시와 재검증했다. 실제 인접 표본 간격은 p50 0.2557초, p95 0.2603초, 최대 0.2974초였다. 이 분위수는 **계측 간격**이며 ASR 지연이 아니다.

현재/누적 제한 비트는 당시 관측 표본에서 0이었고 CPU0 클럭은 중단 표본에서 2.4GHz였다. 따라서 이 기록을 실제 throttling이나 하드웨어 고장으로 부르지 않는다. 외부 판정은 `control_rejected` / `temperature_limit`이며 실제 PID 주소 공간 제한은 확인했다. 강제 종료된 worker의 `running` 상태를 수정하지 않고 외부 판정을 우선했다. 종료 후 guard·worker 부하가 남아 있지 않고 같은 부팅에서 회수했음을 확인했다.

완료 호출은 **85개**, 완전한 50개 순환은 **1회**다. 나머지 35개와 중단 중이던 호출을 480초 완료로 계산하지 않았다. 완료 호출의 CPU/wall 비율은 약 330.4%이며 일부 호출에 한정된 관찰값이다. 관측 TID 최대 8개 중 CPU ≥1%인 TID는 4개로, 설정 2T가 프로세스 전체 2코어 상한은 아니다. 역할·세션 풀·spinning 원인은 미확정이다.

장기 안정성·초반/후반 저하율·새 CER·통제 RTF·Hybrid 지연은 null이다. 중단이 늦어져 호출 수가 늘어난 것을 성능 개선으로 해석하지 않는다. 이번 범위에서 80°C 미만의 장시간 유지 조건을 입증하지 못했다.
