이는 짧은 잔여 구간에서 관측한 실패이며, 길이만이 원인이라는 인과관계는 입증하지 않았다. 경고 무시, 실패 파일 제외 후 전체 성공 표시, 짧은 음성 삭제, 설정 재튜닝은 하지 않았다. 원 캠페인은 Offline 두 실행 뒤 규칙대로 중단했고 **Qwen의 새 자료 온라인 실행을 포함한 원래 온라인 네 조건은 미실행**이다.

후속 개발에서는 짧은 잔여 구간의 합치기/보류 정책을 별도 개발 자료에서 검토해야 한다. 음성을 빠뜨리지 않는지 먼저 확인하고 사전에 고정한 새 평가로 검증한다. 이번에 이미 본 30개는 향후 독립 평가 자료로 다시 사용하지 않는다.
