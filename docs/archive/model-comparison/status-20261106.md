# 현재 상태와 다음 작업

2026-11-06 기준. **Qwen의 기존 KSS batch·VAD·동시 실행 검증 이후, 새 FLEURS 30개에서 1개 실패가 확인됐다.** 기본 SenseVoice와 자동 교체 보류를 유지하며 Qwen 선택은 실험 옵션이다. 별도60°C 시작 조건에서 SenseVoice 새30개 온라인과 두 모델의30분 동시 부하를 완료했다. 두 모델 모두 드롭0이지만 Qwen의 보정 지연과 열 부담이 더 컸다. 원시 회수·기존 파일 보존 감사도 완료했으며 마이크는 아직 없다. 현재 명령은 [사용 안내](../../guides/legacy/live_captions.md), 전체 수치와 근거는 [검증 기록](../../../results/summaries/README.md)에서 확인한다.

WAV MVP의 KSS 첫 stdout p50/p95는 0.853/1.459초, 소유 구간 끝→보정 stdout p95는 0.639초였다. stdout은 파일로 캡처했으며 실제 화면·SSH 도착 지연을 뜻하지 않는다. 기존 모델별 전사는 유지됐다. 수치는 해당 개발 자료의 측정값이다.

[저장소 정리 검증](../../../results/summaries/refactor-20261103.md)에서 Host/RP5 각 287개 테스트와 기존 29개 기록 재집계가 통과했고, 공식 WAV의 짧은 실제 추론도 이전 전사와 일치했다. 모델·환경·기존 기록은 유지했다.

Qwen의 전체 파일 batch 통합 시 Host/RP5는 각 300개 테스트를 통과했다. Qwen CER는 3.57%, SenseVoice는 5.16%였지만 Qwen으로 7개 발화가 악화됐다. Qwen 2T의 batch RTF는 0.6898, 파일 처리 p95는 3.400초, 추론 RSS 관측 최대는 1778.8MiB였다. 세 모델 모두 새 후보 환경에서 비교했고 기존 `.venv`와 당시 보호 대상 5,647개 파일은 유지했다.

후속 VAD·동시 실행과 자막 선택 옵션까지 Host/RP5 각 307개 테스트를 통과했다. 같은 VAD 구간의 KSS CER는 Qwen 3.70%·SenseVoice 5.56%, Qwen 기준 12개 개선·5개 악화·33개 동일이었다. 실제 동시 실행의 전사도 단독과 같았다. Qwen 2T의 구간 끝→보정 반환 p95는 KSS 3.065/3.251초·합성 3.398초, SenseVoice는 0.636/0.602초였다. Qwen 동시 모델 RSS 합 관측 최대는 약 1.98GiB였다. **Qwen은 늦게 도착하는 별도 보정 후보로 제공하며 기본 SenseVoice는 유지한다.**

새 옵션은 공식 3.5265초 WAV 1회에서 실제 후보 표시까지 확인했다. 기존 보호 대상 9,145개 파일과 Python/패키지·CPU/열 설정이 유지됐고, 새 비교/자막 원시 265개 파일을 Host에 회수해 해시를 대조했다.

최신 파일 검증 도구는 Host/RP5 각 **319개 테스트**와 기존 29개 재집계가 통과했다. 새 FLEURS 30개는 기존 문장 ID·정규화 정답·오디오 해시 중복을 제외했고 워밍업도 분리했다. SenseVoice 전체 CER는12.70%, Qwen 전체 CER는 실패 때문에 null이다. 같은 성공29개에서는 Qwen13개 개선·11개 악화·5개 동일이며 우위를 확인하지 못했다. 두 Offline 원시는 Host에 회수해 좌표·PCM·재채점을 검증했다.

첫 캠페인 `file-validation-20261106-01`은 Qwen 실패로 Offline 두 조건 뒤 중단했다. 별도 운영 검사 `file-validation-followup-20261106-01/-02`는 연결·입출력 오류 뒤 사용자 재부팅으로 중단됐고 원시를 회수했다. `-03`은 ASR 시작 전에 유휴55~56°C가 기본53°C 조건을 충족하지 못해 중단됐다. 복구 후 기존13,582개 파일·환경·설정과 별도8MiB 쓰기/읽기를 확인했으나 이전 부팅 journal이 없어 입출력 오류 원인은 미확인이다.

`-04`는 별도 운영 출발 조건60°C·현재 제한없음3회로 세 조건을 완료했다. 실제 시작은 SenseVoice58.95°C·Qwen59.50°C였으며 원래53°C 조건의 통과가 아니다. 소스는 `40529f9`, 기본53°C와 펌웨어 보호/전압/팬/클럭/외부 제한은 유지했다. 기존13,582개 파일 변경·누락0, 환경/설정 동일, 새 결과·자료·점검 기록227개 파일의 Host↔RP5 해시 일치를 확인했다. 저장 요약5개씩의 모델 없는 재집계와 최종 집계 JSON도 두 장비에서 일치했다.

새30개 온라인 SenseVoice는 Offline과 같은86구간·전사·CER12.70%, 보정 반환p95 0.658초였다. Zip CER는50.92%이고11개에서 부분/최종 전사가 비어 있었다. 해당11개는 모두 원음 RMS가−45dBFS 미만이었다. 이는 사후 관측이며 음량만이 원인이라는 증거는 아니다. 입력을 바꾸거나 해당 문장을 평가에서 제외하지 않았다.

반복 합성1,808.803초 단일 입력에서는 두 모델 모두601개 보정 성공·입력/보정 드롭0·종료 보정 백로그0초였다. 보정 반환p95는 SenseVoice0.629초·Qwen3.982초, 동시 모델 RSS 합 최대는1091.7/2432.3MiB였다. Qwen은 최고87.55°C와 열 제한이 관측됐다. RSS 증가도 있어 각1회30분 완료를 누수 부재나 상시 안정성의 증명으로 해석하지 않는다. 자세한 시간 창·분모·제약은 최신 보고서를 따른다.

## 유지하는 결정

- **자동 교체 보류:** M3-5 재생에서 KSS CER는 11.64→8.33%였지만 5개 발화가 악화됐다. 현재 Zip을 유지하고 Refine을 후보로 표시한다. 문자 범위와 실제 입력 음성 범위의 대응을 먼저 검증해야 한다.
- **원음/vad0 유지:** RMS 정규화와 일괄 문맥 확대는 개선과 악화가 함께 나타났다. 모델마다 유리한 전처리를 사후 선택하지 않는다.
- **운영 열 정책:** 기본 펌웨어 보호 아래 온도/감속을 기록한다. 저전압·계측 누락·외부 제한 실패는 거부한다. [정책](m3_thermal_policy.md)의 통제 비교와 운영 검사를 구분한다.
- **평가 자료:** KSS50·이미 본 FLEURS100과 이번에 평가한 validation30은 향후 독립 평가로 재사용하지 않는다. 새30개의 화자 독립과 모델 학습 비중복은 미확인이다. 사용자 청취 메모5개는 판단 어려움으로 남기고 추측 전사를 정답으로 쓰지 않는다. 보류 화자8명/18개는 튜닝에 사용하지 않는다.
- **보존과 배포:** Host 개발→main push→RP5 pull·실측. 모델/환경/원본/과거 결과는 유지하고 새 실행 ID를 사용한다.

## 다음 순서와 완료 기준

1. **짧은 구간의 Qwen 실패:** 56ms 잔여 구간에서 관측한 반복 경고를 별도 개발 자료로 재현한다. 합치기/보류 정책은 원음 누락이 없는지 확인하고 사전에 고정한 새 평가로 검증한다. 이번 새30개의 Qwen 온라인 실행은 Offline 실패로 계속 보류한다.
2. **긴 입력의 메모리 증가:** 모델 프로세스별 RSS와 계측·연속 Zip 상태의 기여를 분리해 원인을 확인한다. 현재30분1회 결과를 무기한 운영 합격으로 대신하지 않는다.
3. **낮은 입력 레벨·실제 마이크:** 장치가 준비되면 지원 샘플레이트·원음 레벨·capture·드롭/백로그를 확인한다. 자연 대화·다화자·잡음의 새 자료와 정답 검수도 필요하다. 이미 평가한 문장을 새 독립 평가로 재사용하지 않는다.
4. **보정 정책:** 음성/문자 범위와 개별 악화를 해결하는 정책을 사전에 고정하기 전까지 자동 교체를 보류한다. 자막 MVP는 Zip 원문·SenseVoice 또는 Qwen 후보를 분리 표시한다.

이번30분 검사는 화면 표시를 끈 공통 `probe-concurrent`다. `live`의480초 입력 상한은 그대로이며, 화면 렌더링·SSH 도착 지연·음소 정렬 인식 지연·실제 마이크·상시 운영은 미검증이다. 이전 입출력 오류 원인도 미확인으로 남긴다. 재학습·자체 재양자화는 후속 과제다. 과거 단계별 계획은 [연구 문서 색인](README.md)에 보존한다.
