# 초기 구조와 확장 방침

## 현재 구현

`src/edge_asr`는 `env`와 `check-config` CLI 및 별도 프로브 반복 실행 모듈을 제공합니다. 기존 CLI의 환경 출력은 설치 메타데이터를 읽으며 모델 런타임을 import하지 않습니다. TOML 검사는 공통 필수 항목의 형식과 양수·음수 범위만 확인합니다.

`scripts/benchmark_zipformer.py`는 설치 없이 `src/edge_asr/benchmark.py`를 호출합니다. 반복 도구는 지정한 기존 가상환경의 자식 프로세스에서 런타임 import를 검사하고 원본 프로브를 실행합니다. WAV 포맷·자산 체크섬, 워밍업/반복·순서, 실패·시간 초과·중단, 로그 파싱·분위수, 전체 프로세스 CPU와 표본 RSS를 담당합니다. 추론 라이브러리를 부모에서 import하거나 원본을 수정하지 않습니다. 자산 경로와 프로브의 100ms 청크·flush 설정은 원본에 고정되어 있습니다. 자세한 측정 범위는 [반복 안내](rp5_repeat_benchmark.md)를 따릅니다.

`configs/zipformer_streaming.toml`은 앞으로 공통 실행기가 사용할 설정 예시입니다. 기존 `experiments/m1_zipformer/streaming_probe.py`는 환경 변수 `ASR_THREADS`와 코드 내 고정 경로를 사용하며 이 TOML을 읽지 않습니다. 설정의 `warmup_runs=3`, `repetitions=30`도 현재 자동으로 실행되지 않습니다.

`experiments/`는 탐색과 출처 보존 영역입니다. 기존 원본을 공통 패키지에서 import하면 파일 입출력·추론이 즉시 실행되므로 import하지 않습니다. 반복 도구도 이를 별도 프로세스로만 실행합니다. 새로운 실험은 별도 파일 또는 하위 디렉터리에 추가합니다.

## 추후 어댑터 경계

처음에는 `src/edge_asr/adapters/zipformer.py` 같은 구체 모듈 하나와 실행 함수로 시작합니다. 설정의 `model.family`는 `zipformer`, `sensevoice`, `qwen3_asr`를 구분할 수 있지만, 이 이름의 수용은 추론 구현이나 지원 보장이 아닙니다. 미구현 모델 선택 시 실행기가 명시적으로 실패하도록 구현합니다.

어댑터가 담당할 것은 모델 로딩, PCM 입력 전달, 부분/최종 결과 수집입니다. 파일·마이크 입력, 정답 정규화, 시간 계측, CPU/RSS 수집, 결과 저장은 공통 실행기에서 담당합니다. 두 번째 실제 백엔드를 구현할 때 공통으로 필요한 계약을 확인하고 최소한의 인터페이스를 추출합니다. 지금은 추상 기반 클래스, 플러그인 레지스트리, 비동기 파이프라인을 만들지 않습니다.

스트리밍을 지원하지 않는 백엔드는 발화 단위 또는 창 단위 처리 능력을 그대로 표시합니다. 창 단위 반복 실행을 네이티브 스트리밍과 같은 의미로 보고하지 않으며 지원하지 않는 부분 자막 지표는 `null`과 사유를 남깁니다. SenseVoice/Qwen3-ASR의 구체 실행 방식·양자화·메모리 적합성은 아직 검증하지 않았습니다.

## 단계별 완료 조건

1. 초기 골격: 소스 설치·설정 검사·문서·원본 무결성 확인. 현재 범위입니다.
2. RP5 기준선: 반복 요약과 후속 사용자 전달 RP5 Codex 검사 보고에서 측정 90/90·워밍업 9회 성공, 통합·자산·환경 일치, 단위 테스트 35개 통과가 확인됐다고 보고됐습니다. 이번 단일 WAV에서는 2스레드를 잠정 기준값으로 유지합니다. [기록](../results/summaries/zipformer-repeat-20261028-reported.md)에 출처·한계를 명시하며 Host 직접 재실행이나 원본 파일 전송과는 구분합니다. 원시 결과는 RP5의 내부 백업에 보존합니다.
3. 공통 평가: 정답 manifest, CER 정규화, 별도 batch/paced-stream 실행기, 이벤트 시간 및 CPU/RSS·백로그 계측.
4. 모델 비교: 동일 corpus와 측정 조건에서 SenseVoice/Qwen3-ASR 어댑터 추가, 실패·OOM도 결과로 기록.
5. 실시간 배포: 마이크 캡처 큐, 드롭 정책, endpoint, 자막 소비자와 systemd 서비스, 장시간 안정성 검사.

사용자 제공 요약은 그 출처로만 기록하고 직접 실행·원시 자료 검증과 구분합니다. 상주 어댑터와 공통 평가 이후 단계는 계획이며 아직 구현·검증한 것으로 표시하지 않습니다.
