# 약 1분 긴 발화 개발·회귀 세트

2026-11-17 준비한 `longform-20261117-01`은 **12개·732.6568125초(약 12분 13초)**입니다. 각 음원은 52.8506875~70.8513125초이며, 기존 고정100개를 유지하면서 긴 문맥과 반복 분할을 확인하는 별도 자료입니다. 공통 `dataset.py` 입력·기존 연속 평가기·`ko_cer_v1` 채점을 그대로 사용합니다.

## 구성과 정답 범위

| 조건 | 개수 | 구성 |
| --- | ---: | --- |
| 자연발화·높은 발화 비율 | 2 | 10대 남성·30대 여성, 발화 라벨 비율 약79%·88% |
| 자연발화·간투사 다수 | 2 | 10대 여성·30대 남성, 어/음/아/그/뭐 토큰16·24개 |
| 자연발화·쉼 다수 | 2 | 20대 남성·40대 여성, 0.5초 이상 SIL 라벨15·13개 |
| 자연발화·웃음 포함 | 2 | 20대 여성·40대 남성, LAUGH 라벨 약1.56·2.30초 |
| 낭독 연결·추가 무음0초 | 2 | 남녀 각1개, 화자별 서로 다른 완전한 원본 발화를 연결 |
| 낭독 연결·추가 무음1.2초 | 2 | 남녀 각1개, 원본 발화 사이에만 무음 삽입 |

자연발화는 [Seoul Corpus / OpenSLR113](https://www.openslr.org/113/)의 서로 다른 화자8명, 낭독 연결은 [Zeroth-Korean / OpenSLR40](https://www.openslr.org/40/)의 서로 다른 화자4명입니다. 전체 남녀 각6개입니다. 원본·메타데이터는 기존 로컬 캐시를 재사용했고 새 다운로드·패키지 설치·TTS 생성은 하지 않았습니다. 자연발화는 CC BY-NC2.0, 낭독은 CC BY4.0이며 인용·출처를 `provenance.json`에 남겼습니다. 기존 개인·학술 연구용 이용 범위는 [확보 기록](../archive/model-comparison/m3_public_vad_data.md#출처와-사용-범위)을 따릅니다.

위 특성은 **원본 라벨에서 계산한 선정 지표**입니다. 간투사 계수에는 대명사로 쓰인 ‘그’ 등이 들어갈 수 있으며, 정확한 머뭇거림·자기 수정 주석을 뜻하지 않습니다. 말하기 속도는 별도 계측하지 않았습니다. 자연발화와 합성 연결, 서로 다른 화자 조건을 인과 대조로 해석하지 않습니다.

배포처 `utt.ortho.` 전사를 사용합니다. 띄어쓰기·구어형·반복·간투사를 임의로 교정하지 않았습니다. `<IVER>`(면접자), `<UNKNOWN>`, `<PRIVATE.INFO>`, 단어가 섞인 웃음 태그 등 정답을 완전히 구성하기 어려운 라벨이 들어간 **후보 전체를 제외**합니다. 허용한 SIL/VOCNOISE/LAUGH/NOISE 라벨은 정답 문자에 넣지 않지만 해당 소리는 WAV에 그대로 남깁니다. 따라서 무음·웃음·호흡 구간이 음원에서 삭제된 것은 아닙니다.

**새로 독립 청취 검수한 정답은 아닙니다.** 배포 전사 기반 개발/회귀 CER용이며, 사람 검수 완료·독립 holdout·자연 대화 전체의 대표성을 주장하지 않습니다. 과거 Seoul 검수 후보와 같은 코퍼스/화자가 포함될 수 있고, 모델 학습 중복도 미확인입니다. 단어별 음향 종료 시각은 미검수이므로 음향 지연 정답으로 사용하지 않습니다. 낭독 연결은 기존100개와 정규화 원문 중복을 제외했지만, 새 연결 음원들 사이에서 같은 문장을 다른 화자가 읽은 경우는 남아 있습니다.

## 선정·변환

`tools prepare-longform`이 기존 준비 도구의 원본 검사/변환, `textgrid.py`의 엄격한 파서, `artifacts.py`의 해시·JSON 기록을 재사용합니다. 별도 모델 평가기를 만들지 않습니다.

1. 로컬 확보 기록에 고정한 Seoul 라벨/음성 ZIP SHA-256과 Zeroth 부분 archive SHA-256을 확인합니다. 이 해시는 로컬 확보 원본 식별값이며 공개 공식 체크섬과의 대조 범위는 기존 확보 문서를 따릅니다.
2. TextGrid240개를 검사합니다. 잘못된 파일은 사유를 감사 목록에 남기며, 이번 원본은240개 모두 파싱에 성공했습니다. 각 발화 라벨 시작점에서50~75초 안의 종료 라벨 중60초에 가장 가까운 후보를 만듭니다. 배제 라벨을 넘지 않습니다.
3. 사전에 정한 연령대·성별8할당에서 해당 조건 지표가 큰 후보를 고릅니다. 동률은60초와의 차이와 고정 seed의 ID 해시로 결정합니다. ASR 출력·VAD 추론은 선정에 사용하지 않습니다.
4. 자연발화는 원본 전체를 기존 ffmpeg로16kHz 모노 PCM16 변환한 뒤 `round(시각×16000)`의 `[start,end)` 프레임을 한 번 절취합니다. 구간 내부 무음·발화 순서·속도·음량을 보존하며 양끝은 **발화 라벨 경계**이지 의미상 완결 문장 보장은 아닙니다.
5. Zeroth는 기존100개 정규화 정답을 제외하고 남녀/무음 조건마다 다른 화자를 선택합니다. 완전한 원본을 ID순으로 연결해60초 이상을 채우되80초를 넘지 않습니다. 원본 반복으로 길이를 늘리지 않으며 source별 프레임·전사·PCM 해시를 보존합니다.

## 파일과 실행

저장 위치는 `data/evaluation/longform-20261117-01/`입니다.

```text
longform-20261117-01/
├── original/          # 선택 원본 FLAC·TextGrid·Zeroth 전사/화자 정보
├── wav/               # 16kHz mono PCM16 WAV 12개
├── label-audit.jsonl  # TextGrid240개 검사
├── manifest.jsonl     # 전체12개, 자연발화8개 다음 낭독4개
├── natural.jsonl      # 자연발화8개
├── provenance.json    # 조건·출처·라이선스·전체 파일 해시
├── reading.jsonl      # 낭독 연결4개
└── statistics.json    # 길이·조건·정답 문자 집계
```

```bash
# 준비된 원본 캐시로 생성. 기존 완성 경로가 있으면 덮어쓰지 않고 검증.
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/edge_asr.py tools prepare-longform

# 모델·ffmpeg·원본 캐시·네트워크 없이 완성된 자료 재검증
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/edge_asr.py tools prepare-longform --verify-only

# 다른 준비 실행은 새 경로로 구분
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/edge_asr.py tools prepare-longform \
  --output data/evaluation/<새ID>
```

실제 평가는 [현재 공유 설정·대표 명령](../guides/qwen3_optimization.md#현재-개발용-대표-명령)의 `--manifest`를 이 세트의 `manifest.jsonl`, `natural.jsonl`, `reading.jsonl` 중 하나로 바꾸고 새 실행 ID를 사용합니다. **1분 WAV를 통째로 batch 모델 호출에 넣지 않고 기존1배속 연속 입력 평가기에서 최대5초 구간으로 처리**합니다. 별도 워밍업·유한 큐·운영 온도 정책을 유지합니다. 파일 사이 추가 무음은0초이고 낭독의1.2초는 음원 내부에 이미 포함되어 있습니다.

Host 개발·검사 → main 반영/push → RP5 동기화·파일 검증 → 필요한 실제 추론 순서를 따릅니다. 원본 전체 캐시 없이 완성 폴더만 전달해 재검증할 수 있습니다. 준비 스크립트는 새 폴더만 만들고, 준비 실패의 `.preparing-*` 폴더도 보존합니다.

전체/자연발화/낭독을 구분해 CER·삽입/삭제·실패/드롭·갱신 공백·최종 반환 지연을 보고합니다. 표본이 작으므로 p95만으로 일반화를 하지 않고 음원별 결과도 확인합니다. 원음 경계를 넘는 확정 전사는 기존 귀속/연결 채점 계약을 유지합니다.

## 준비 검증과 미측정

Host에서12개 WAV의 형식·길이·해시·정답 유효성, 전체/부분 목록 일치, 자연발화의 원본 라벨·절취 좌표·전사, 낭독 연결의 무음/원본 PCM/전사 순서를 확인했습니다. 별도 ffmpeg 재디코딩으로 자연발화8개의 원본 절취 PCM과 낭독4개의 원본 연결 PCM을 결과 WAV에 대조했습니다. 전체 원시 검증 기록은 `results/maintenance/longform-preparation-20261117-01/verification.json`입니다.

모델 없는 테스트는 배제 라벨을 넘는 후보 거부, 원음 프레임 절취, 결정성·할당량 부족 거부, 기존 정답 제외·화자 분리를 검사합니다. 준비 시점 스크립트 해시를 보존하며 이후 검증 함수 보강으로 현재 파일 해시가 다를 수 있습니다. 준비 당시 RP5 추론·CER·지연·사람 청취 검수는 미실행/미측정이었습니다. 이후 [2026-11-18 RP5 긴 음원 대조](../../results/summaries/optimization/longform-stream-20261118.md)에서 기존 Q4와1.99초 창 캐시의 CER·지연·실패·열 상태를 측정했습니다. 독립 사람 청취 검수는 아직 미완료입니다.

Host 전체 회귀456개 중452개 통과·선택 native 헤더 검사4개 생략, Ruff 검사/포맷·M1 원본 보존·공유 설정 검사와 기존 고정100개 재검증을 통과했습니다. 전체 회귀 로그는 같은 검증 기록 폴더의 `host-unittest.txt`에 보존했습니다.
