# 초기 저장소 구성 검증 기록

검증일은 2026-10-27(Asia/Seoul)입니다. 검증 환경은 로컬 Linux x86_64, CPython 3.11.14이며 RP5가 아닙니다. RP5 연결·패키지 설치·모델 추론·성능 재측정은 수행하지 않았습니다.

| 항목 | 실제 수행 결과 |
| --- | --- |
| 기본 패키지 설치 | 새 로컬 `.venv`에서 `python -m pip install -e .` 성공. 추론 선택 의존성은 설치하지 않음 |
| 단위 검사 | `python -m unittest discover -s tests -v`: 6개 테스트 통과(설정 경계값 subtest 포함) |
| 의존성 검사 | 기본 설치의 `python -m pip check` 통과 |
| CLI | 설치된 `edge-asr env`, `edge-asr check-config configs/zipformer_streaming.toml` 성공 |
| wheel 빌드 | `python -m pip wheel --no-deps . --wheel-dir dist` 성공. `edge_asr-0.1.0-py3-none-any.whl` 생성; Git 제외 |
| 원본 무결성 | `sha256sum -c experiments/m1_zipformer/SHA256SUMS`: 원본 프로브 및 결과 3개 모두 일치 |
| 요약 일치 | `summary.json`의 세 스트리밍 실행별 첫 부분 시점·최종 경과·최종 지연·최대 초과 값이 원시 로그와 일치 |
| Git 제외 규칙 | 모델·오디오·가상환경·캐시·실행 결과 등 제외 사례 12개, 작은 요약·보존 원본·안내 문서 등 허용 사례 6개 확인 |
| 문서 링크 | Markdown의 저장소 내부 상대 링크 대상 존재 확인 |
| 배포 구문·동작 | Bash 구문 검사 및 로컬 임시 디렉터리 스모크 검사 통과. 기본 dry-run, 실제 복사, 기존 파일 내용 보존, 가상환경·자산 제외, 잘못된 인자 거부 확인 |

배포 동작 검사는 임시 `rsync` 래퍼에서 원격 대상 인자를 **로컬 임시 경로로 치환**하여 실제 로컬 rsync를 호출한 것입니다. SSH 통신이나 실제 RP5 파일을 사용하지 않았으므로 원격 접속·권한·운영 환경 호환성은 미검증입니다.

처음에는 로컬 `python3.11` 심볼릭 링크로 `venv` 생성 시 표준 라이브러리 경로 오류가 발생했습니다. 해당 인터프리터의 실제 실행 파일 경로로 이번 작업에서 만든 가상환경을 재생성한 뒤 위 설치·검사를 통과했습니다. 이 Host 경로 문제를 RP5에서 재현하거나 수정한 것은 아닙니다.

PyPI 메타데이터로 후보 의존성 NumPy 1.26.4, sherpa-onnx 1.12.40 및 전이 의존성 sherpa-onnx-core 1.12.40의 Python 3.11 호환 Linux aarch64 wheel 존재를 확인했습니다. 이는 wheel 메타데이터 확인이며 실제 ARM64 설치나 추론 검증은 아닙니다.

다음 검증은 RP5의 별도 Python 3.11 가상환경 설치, 실제 모델·WAV 읽기, 기존 프로브의 새 실행, 환경 메타데이터와 반복 측정 기록입니다. 첫 부분 출력·최종 지연의 기존 수치는 여전히 단일 샘플 설정별 1회 측정입니다.

## 2026-10-28 반복 도구 추가 검증

사용자가 제공한 RP5 출력에서 기존 Python 3.11 가상환경 설정과 필요한 모델·WAV 파일 목록을 확인했습니다. 기존 환경을 변경하지 않고 사용하는 반복 도구를 추가했습니다. 원격 장비에서 직접 확인한 결과와는 구분합니다.

로컬 Linux x86_64 / CPython 3.11.14에서 전체 단위 검사 21개를 통과했습니다. 신규 검사는 원본 로그 세 개 파싱, nearest-rank와 단일 관측 분위수 결측 처리, 99회 교차 실행 순서, 임시 합성 WAV 포맷·체크섬, 모의 프로브 성공·비정상 종료·시간 초과·사용자 중단 정리, 워밍업 제외·실패 중단, 측정 실패 후 다른 조건 계속 실행, 기존 파일 보존, 사전 검사 실패 기록을 포함합니다.

별도 프로세스에서 설치 없는 `scripts/benchmark_zipformer.py` 진입점도 확인했습니다. 임시 모의 NumPy/sherpa-onnx 모듈과 모의 프로브·합성 WAV를 사용하여 환경 검사 → 실행 4회 → JSON/Markdown 요약 생성을 통과했습니다. 실제 모델·ASR 런타임·RP5를 사용한 검증이 아닙니다.

원본 프로브 및 결과 3개의 SHA-256은 초기 기록과 모두 일치합니다. CLI 도움말, Python 구문 검사 및 배포 Bash 구문 검사도 통과했습니다. 실제 RP5의 런타임 import·반복 추론·자원 수집·네트워크 배포는 아직 수행하지 않았습니다. 실행 절차는 [반복 벤치마크 안내](rp5_repeat_benchmark.md)를 따릅니다.
