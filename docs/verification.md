PyPI 메타데이터로 후보 의존성 NumPy 1.26.4, sherpa-onnx 1.12.40 및 전이 의존성 sherpa-onnx-core 1.12.40의 Python 3.11 호환 Linux aarch64 wheel 존재를 확인했습니다. 이는 wheel 메타데이터 확인이며 실제 ARM64 설치나 추론 검증은 아닙니다.

다음 검증은 RP5의 별도 Python 3.11 가상환경 설치, 실제 모델·WAV 읽기, 기존 프로브의 새 실행, 환경 메타데이터와 반복 측정 기록입니다. 첫 부분 출력·최종 지연의 기존 수치는 여전히 단일 샘플 설정별 1회 측정입니다.

## 2026-10-28 공통 파일 평가·재채점 구현

Host Linux x86_64 / CPython 3.11.14에서 전체 테스트 63개를 통과했습니다. 신규 28개는 정답 정규화·S/D/I·빈 정답·문자 수 가중 CER·오디오 길이 가중 RTF·실패 커버리지, 목록 중복·잘못된 WAV/설정·NaN 거부, 모델 1회 로드·새 스트림·워밍업 제외·중단/실패, 기존 결과 불변, 모델·오디오 제거 후 재채점, 정답 ID 일치 및 독립 CLI를 포함합니다. 가짜 시계로 모델 준비·워밍업 시간이 RTF에 들어가지 않음을 검사했습니다.

독립 CLI 평가도 임시 합성 WAV·가짜 NumPy/sherpa 모듈로 수행했습니다. 이는 실제 ONNX 추론·한국어 정확도·ARM64 API 호환성을 검증한 결과가 아닙니다. 기존 RP5의 Python·가중치·WAV·실험 결과는 변경하지 않았으며 실제 RP5 공통 평가 실행은 다음 검증입니다. 정답을 사람이 확인한 목록으로 [평가 안내](evaluation.md)를 따라 실행합니다.

최종 wheel 빌드가 성공했고 공통 입력·실행·채점·어댑터 모듈 포함 및 가중치·WAV·가상환경 미포함을 확인했습니다. 문서 상대 링크·Bash 구문·새 파일 공백, 예시 manifest 추적 허용과 실제 데이터/결과 Git 제외, 보존 프로브 체크섬도 확인했습니다. 빌드 산출물은 Git 제외 `dist/`에 두었습니다.
