# 현재 상태와 다음 작업

2026-10-29 기준입니다. 구현·단위 테스트·RP5 실제 추론·사람 검수를 각각 구분합니다. 자세한 수치와 원시는 [실측 기록](../results/summaries/README.md)에 연결합니다.

| 단계 | 확인한 범위 | 남은 조건 |
| --- | --- | --- |
| M1 기준선 | Zipformer batch·paced_stream, KSS 개발 50개, 공통 평가·재채점 | 실제 마이크·정렬 인식 지연 |
| M2 모델 비교 | SenseVoice INT8 batch, 1/2/4스레드 비교, FLEURS·스트레스 입력 | 관측 발열·자료 특성을 고려한 해석; Qwen 이후 검토 |
| M3 사전 검증 | 공통 원음/RMS, Silero VAD, 유한 PCM/구간 상한, 공개 자료 준비·예비 비교 | 사람 검수 정답, 지속 음성 처리, 고부하 냉각 |
| M3-1 동시 실험 | 측정 계획과 조합 후보 | 동시 ASR 런타임·실측은 미구현 |

다음 순서는 다음과 같습니다.

1. 공개 개발 자료의 새 누락·공통 누락·잡음 검출을 실제 청취/파형으로 검수하고, 나머지 개발 구간도 같은 기준으로 확정합니다. [검수 결정 반영 도구](research/m3_vad_annotations.md)를 사용하며 자동으로 사람 검수 상태를 붙이지 않습니다. 보류 화자 8명/18개는 튜닝에 사용하지 않습니다.
2. 검수된 같은 입력으로 VAD/전처리 후보를 비교합니다. 현재 RMS는 예비 누락을 줄였지만 새 누락과 비음성 검출 증가가 있어 채택 보류입니다.
3. native VAD가 30초 이상 계속 활성인 입력을 처리할 방식을 별도로 검증합니다. 현재는 예산을 넘기기 전에 실패 중단하며 무중단 서비스라고 주장하지 않습니다.
4. 기존 Zipformer 2T 고부하 냉각 중단 조건을 재검증합니다. 가벼운 VAD가 열 제한을 통과한 것으로 대체하지 않습니다. 팬·히트싱크·통풍의 물리적 확인이 필요한 조건은 별도 기록합니다.
5. 조건을 통과한 뒤 Zipformer 1T+SenseVoice 1T, 1T+2T, 2T+1T를 실제 동시 실행해 첫 부분 출력·Refine 대기·자원·온도·드롭/백로그를 계측합니다. 단독 batch 수치로 예측하지 않습니다.

이번 구조 정리는 실행 경로·공통 코드·문서 탐색을 개선하는 작업입니다. 기존 측정값이나 정책 승인 상태는 바꾸지 않습니다.
