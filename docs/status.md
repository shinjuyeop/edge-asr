## 유지하는 연속 입력 기준

**Qwen 단독1배속 연속 입력**이 주 평가입니다. 공유 고정 참조는 **GGUF Q8_0·생성2T/음성·prefill3T·VAD 보정·ASR/VAD 판정5초·첫1초/이후4초·토큰 표시/접두부 재표시 보류·고정 text prefix KV**입니다. [configs/gguf_realtime.toml](../configs/gguf_realtime.toml)과 [대표 명령](guides/qwen3_optimization.md#현재-개발용-대표-명령)을 사용합니다. 기존 캐시 끔2/3 원본 `results/optimization/opt3/realtime-split100-20261111-01/configs/split-2-3.toml`과 기본2T·모두3T 설정·모델·환경·bridge는 보존합니다. 실사용 채택은 보류합니다.

사용자 청취 피드백은 잦은 수정보다 빠른 갱신을 선호했습니다. **후속 저지연 개발 비교는 Q8 음성비용 가변**을 기준으로 합니다. 같은 모델 설정에 `adaptive/budgeted/audio`·3초/최대2회·새 음성0.8초·끝 여유0.2초를 명시하며, 공유 고정 프로필은 회귀 참조로 보존합니다. [가변 실행 옵션](guides/qwen3_optimization.md#가변-부분-요청-선별).

커널 진단 뒤 사용자 결정으로 **주력은 Q8 text/audio·생성2T/음성·prefill3T**에 집중합니다. Q4 모델·계측·실측은 별도 연구 후보로 보존합니다. 다음은 첫 요청 목표0.6초/현재1초/2초를 같은6개 연속 입력에서 비교하는 계획이며 아직 실행하지 않았습니다. 이 방향 정리는 모델·공유 설정·기존 수치를 변경하지 않습니다.

개발·검증 절차는 [CONTRIBUTING](../CONTRIBUTING.md), 직접 확인한 Host/RP5 버전과 환경별 용도는 [환경 기록](reference/environment.md)에 정리했습니다. 구조·안내 정리는 아래 실측의 재실행이나 성능 갱신을 뜻하지 않습니다.
