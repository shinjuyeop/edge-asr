# 현재 상태와 다음 작업

2026-11-02 기준입니다. 구현·단위 테스트·RP5 실제 추론·사람 검수를 각각 구분합니다. 자세한 수치와 원시는 [실측 기록](../results/summaries/README.md)에 연결합니다.

| 단계 | 확인한 범위 | 남은 조건 |
| --- | --- | --- |
| M1 기준선 | Zipformer batch·paced_stream, KSS 개발 50개, 공통 평가·재채점 | 실제 마이크·정렬 인식 지연 |
| M2 모델 비교 | SenseVoice INT8 batch, 1/2/4스레드 비교, FLEURS·스트레스 입력 | 관측 발열·자료 특성을 고려한 해석; Qwen 이후 검토 |
| M3 사전 검증 | 공통 원음/RMS, VAD 비교·30초 초과 활성 공학 검사, 유한 PCM/구간 상한, 고온 감속 포함 단독 8분 부하 | 사람 검수 정답, 자연 장문·마이크·장시간/동시 운영 |
| M3-1 동시 실험 | 측정 계획과 조합 후보 | 동시 ASR 런타임·실측은 미구현 |

사용자의 청취 메모 5개는 모두 **판단 어려움**으로 보존했습니다. 추측 전사는 정답으로 사용하지 않고 기존 예비 주석·측정값을 유지합니다. 지금 추가 청취를 요청하지 않으며, 사람 판단 없이 가능한 구조 검증과 냉각 기록 분석을 먼저 진행합니다.

다음 순서는 다음과 같습니다.

1. [이전 개발 자료 비교](../results/summaries/m3-bounded-vad-rp5-20261102.md)에 이어 [중첩 공학 입력](../results/summaries/m3-vad-overlap-rp5-20261102.md)에서 실제 모델의 **원음 37.572초/RMS 34.788초 연속 활성**을 검증했습니다. bounded는 3/5/8초 구간·PCM·버퍼·reset 검사를 통과했고 native는 30초 안전 예산으로 6회 중단했습니다. 연결 복구 후 원시 42개와 기존 파일 4,009개의 해시 대조를 완료했습니다. 자연 장문/마이크 검증이나 정책 채택을 의미하지 않으며 기존 기본값과 안전 예산을 유지합니다.
2. 공개 개발 자료의 확정 가능한 구간만 실제 청취/파형으로 검수할 때 [검수 결정 반영 도구](research/m3_vad_annotations.md)를 사용합니다. 불확실 사례를 자동으로 사람 검수 상태로 바꾸지 않습니다. 보류 화자 8명/18개는 튜닝에 사용하지 않습니다.
3. 검수된 같은 입력으로 VAD/전처리 후보를 비교합니다. 현재 RMS는 예비 누락을 줄였지만 새 누락과 비음성 검출 증가가 있어 채택 보류입니다. 자연 장문·마이크에서의 구간 경계와 장시간 운영 검증도 별도로 필요합니다.
4. 과거 [75°C](../results/summaries/m3-cooling-recheck-20261102.md)/[80°C 중단 검사](../results/summaries/m3-thermal80-20261102.md)는 그대로 보존합니다. 사용자 승인으로 [운영 정책](research/m3_thermal_policy.md)을 추가해 기본 열 보호 아래 [Zipformer 2T 8분 부하](../results/summaries/m3-operational-20261102.md)를 완료했습니다. 1,203회·완전 순환 24회, 최고 관측 85.9°C, 실제 감속/스로틀링이 있었습니다. 진단 batch RTF 0.1209, 같은 50개 순환의 첫/마지막 추론 시간은 17.871/20.635초였습니다. 운영 검사는 온도만으로 막지 않으며 통제 비교 결과와 구분합니다. 팬/OS/모델/환경 설정과 과거 재현용 기본값은 유지합니다.
5. [자연 발화 구간 CER 평가](research/m3_segmentation_accuracy.md)는 기존 KSS 50개·전사 756자·원본 해시와 full/fixed5/VAD5 조건을 준비했습니다. 새 ASR 실행/도구 구현은 하지 않았고 사람 검수 음소 경계·마이크 지연은 별도입니다.
6. 구간 정확도 확인 뒤 Zipformer 1T+SenseVoice 1T, 1T+2T, 2T+1T를 실제 동시 실행해 첫 부분 출력·Refine 대기·자원·온도·드롭/백로그를 계측합니다. 운영 정책에서 열 제어가 작동할 때의 실제 성능도 기록하며 단독 batch 수치로 예측하지 않습니다.

기존 측정값이나 정책 승인 상태는 바꾸지 않습니다. 실제 연결과 검증이 끝나기 전에는 새 경로의 RP5 성공 또는 M3 전체 완료로 표시하지 않습니다.
