# 현재 상태와 다음 작업

2026-10-29 기준입니다. 구현·단위 테스트·RP5 실제 추론·사람 검수를 각각 구분합니다. 자세한 수치와 원시는 [실측 기록](../results/summaries/README.md)에 연결합니다.

| 단계 | 확인한 범위 | 남은 조건 |
| --- | --- | --- |
| M1 기준선 | Zipformer batch·paced_stream, KSS 개발 50개, 공통 평가·재채점 | 실제 마이크·정렬 인식 지연 |
| M2 모델 비교 | SenseVoice INT8 batch, 1/2/4스레드 비교, FLEURS·스트레스 입력 | 관측 발열·자료 특성을 고려한 해석; Qwen 이후 검토 |
| M3 사전 검증 | 공통 원음/RMS, Silero VAD, 유한 PCM/구간 상한, 공개 자료 준비·예비 비교 | 사람 검수 정답, 지속 음성 처리, 고부하 냉각 |
| M3-1 동시 실험 | 측정 계획과 조합 후보 | 동시 ASR 런타임·실측은 미구현 |

사용자의 청취 메모 5개는 모두 **판단 어려움**으로 보존했습니다. 추측 전사는 정답으로 사용하지 않고 기존 예비 주석·측정값을 유지합니다. 지금 추가 청취를 요청하지 않으며, 사람 판단 없이 가능한 구조 검증과 냉각 기록 분석을 먼저 진행합니다.

다음 순서는 다음과 같습니다.

1. [실험용 확률 VAD와 냉각 진단](research/m3_bounded_vad.md)의 Host 구현·모의 검사를 마쳤습니다. 기존 네이티브 경로와 30초 안전 예산을 유지하며, 선택적 bounded 경로만 파형 축적 없이 동작합니다. RP5 SSH 연결 실패로 새 ARM64 추론·실측·소스 동기화는 미완료입니다.
2. 공개 개발 자료의 확정 가능한 구간만 실제 청취/파형으로 검수할 때 [검수 결정 반영 도구](research/m3_vad_annotations.md)를 사용합니다. 불확실 사례를 자동으로 사람 검수 상태로 바꾸지 않습니다. 보류 화자 8명/18개는 튜닝에 사용하지 않습니다.
3. 검수된 같은 입력으로 VAD/전처리 후보를 비교합니다. 현재 RMS는 예비 누락을 줄였지만 새 누락과 비음성 검출 증가가 있어 채택 보류입니다. 지속 음성의 실제 모델/구간 검증도 별도로 필요합니다.
4. 기존 Zipformer 2T 고부하 냉각 중단 조건을 재검증합니다. 과거 팬 RPM 증가를 확인했지만 75°C 중단 기준 실패는 유지합니다. 가벼운 VAD가 열 제한을 통과한 것으로 대체하지 않습니다. 물리적 상태가 필요한 조건은 원격 진단 이후 별도 기록합니다.
5. 조건을 통과한 뒤 Zipformer 1T+SenseVoice 1T, 1T+2T, 2T+1T를 실제 동시 실행해 첫 부분 출력·Refine 대기·자원·온도·드롭/백로그를 계측합니다. 단독 batch 수치로 예측하지 않습니다.

기존 측정값이나 정책 승인 상태는 바꾸지 않습니다. 실제 연결과 검증이 끝나기 전에는 새 경로의 RP5 성공 또는 M3 전체 완료로 표시하지 않습니다.
