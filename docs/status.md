## 유지하는 연속 입력 기준

**Qwen 단독1배속 연속 입력**이 주 평가입니다. 공유 고정 참조는 **GGUF Q8_0·생성2T/음성·prefill3T·VAD 보정·ASR/VAD 판정5초·첫1초/이후4초·토큰 표시/접두부 재표시 보류·고정 text prefix KV**입니다.
