# 현재 상태 — Qwen3-ASR 최적화

2026-11-11 기준. 목표는 **RP5에서 Qwen3-ASR-0.6B의 한국어 정확도·완료율을 유지하면서 실제 인식 지연을 줄이는 것**입니다. [연구 계획](research/qwen3_optimization.md), [평가 조건](research/qwen_realtime.md), [최신 실측](../results/summaries/optimization/realtime-schedule-20261111.md).

## 현재 연속 입력 기준

**Qwen 단독1배속 연속 입력**을 주 평가로 사용합니다. ONNX INT8 2T를 출발 기록으로 보존하고 GGUF Q8_0 2T의 입력 처리·지연을 개선했습니다. **다음 개발 기준은 Q8·VAD 보정·ASR5초·VAD 판정5초·첫1초/이후4초**입니다. 실사용 통과 구성은 아닙니다.

같은 Zeroth60·FLEURS40·891.1448125초·정답3848자·추가 무음0초입니다. VAD0.3·보정·문맥0·구간5초·같은 유한 큐에서 추론 중에도 입력을 계속 받았습니다. 첫 요청1초를 유지하고 이후 부분 갱신 간격만2초→4초로 바꿔 같은 소스에서 두 구성을 새로 전사했습니다. 최종210개 구간의 좌표·PCM·전사가 모두 같습니다.

4초 간격은 사전 개발 조건을 모두 통과했습니다. 부분 추론 시간 합계가약51% 줄고 최종 큐 대기도 감소했습니다. 부분 자막 갱신은 뜸해지는 절충이 있으며 부분 가설 정확도·수정 안정성은 별도 검증 대상입니다. 파일 끝 기준 반환은 원음 입력 끝→마지막으로 겹치는 최종 호출 반환이며 음향 단어 끝은 아닙니다.

두 설정 모두 원음100개에 자막이 있고 최종 경계 중첩1개가 남아 발화별 corpus CER는null입니다. 전체 정답3848자를 연결 CER에 포함합니다. 같은 순서 기존 batch 연결 CER7.64%보다 오류가 남아 있고 열 제한도 관측되어 **저지연 실사용 채택은 보류**합니다. 단일 순차 운영 대조이며 한국어 전반의 개선이나 순수 엔진 효과로 일반화하지 않습니다.

## 구현·검증

- 기존 `qwen/realtime/` 실행기와 ONNX/GGUF 어댑터·공통 입력/채점을 재사용합니다. 각 호출은 누적 PCM의 batch 전사이며 청크 간 KV 재사용·토큰 즉시 배포는 미구현입니다. [구조](reference/architecture.md).
- 기존 실행기의 갱신 간격 선택지에4초만 추가했습니다. 기본값·패키지·모델·native 코드는 보존합니다. 이번 Host/RP5 각 연속 입력9개·구조/문서/CLI6개 검사 통과. 이전 전체363개 중361개 통과·native2개 생략은 [정확도 회복 기록](../results/summaries/optimization/realtime-accuracy-20261110.md)에 있습니다.
- 이번 고유6개 대조2건·100개 전체 대조2건의 원시·검증 기록55개와 기존 자산5개 해시가 일치합니다. 양쪽에서 재집계한 JSON도 바이트가 같고 같은 부팅 ID를 유지했습니다. [원시 경로·검증 상세](../results/summaries/optimization/realtime-schedule-20261111.md).
- 첫 ONNX 시도의 예기치 않은 재시작과 이후 화면·입력 멈춤 원인은 미확정으로 보존합니다. 새 ONNX02·GGUF 실행은 같은 부팅을 유지하며 입력을 완료했습니다. 시스템 멈춤과 모델 출력 실패를 구분합니다.
- 현재100개는 낭독 개발/회귀 자료입니다. 마이크·자연 대화·잡음·독립 holdout·최종 장시간 검증은 미완료입니다. [데이터 출처·한계](research/fixed100.md).

## 다음 작업

1. **Q8·VAD 보정·구간5초·첫1초/이후4초**를 기준으로 생성 중 텍스트를 먼저 배포할 수 있는 범위를 검토합니다. 첫 자막·부분 수정·실패·정확도를 함께 관리합니다.
2. 음성 처리/prefill·안전한 캐시 재사용과 남은 분할/문맥 손실을 분리합니다. 현재 청크 간 KV 재사용은 미구현이고 engine TTFT·음향 단어 시각은 미측정입니다. batch 대비 오류134개도 남아 있습니다.
3. Q5/Q6/Q4는 기존 고유3개 선별 결과입니다. 최종 양자화 선정은 같은 연속 조건의 정확도·실패·누락·지연으로 판단합니다.
4. ONNX의 긴 파일 context 거부와1.496초 출력 상한 실패, 시스템 멈춤 원인은 별도 진단으로 다룹니다. 이후 독립 자료·마이크·장시간 운영을 검증합니다.
