# 현재 상태와 다음 작업

2026-11-06 기준. **Qwen3-ASR-0.6B INT8의 공통 batch 평가와 같은 VAD 구간·Zip 동시 실행 검증을 완료했다. WAV 자막에서 Qwen 2T를 별도 후보로 선택할 수 있다.** 기본 SenseVoice와 자동 교체 보류는 유지한다. 다음은 실제 사용 자료·독립 평가·장시간 검증이며 마이크 입력은 장치 준비를 기다린다. 현재 명령은 [사용 안내](guides/live_captions.md), 전체 실험의 수치와 근거는 [검증 기록](../results/summaries/README.md)에서 확인한다.

WAV MVP의 KSS 첫 stdout p50/p95는 0.853/1.459초, 소유 구간 끝→보정 stdout p95는 0.639초였다. stdout은 파일로 캡처했으며 실제 화면·SSH 도착 지연을 뜻하지 않는다. 기존 모델별 전사는 유지됐다. 수치는 해당 개발 자료의 측정값이다.

[저장소 정리 검증](../results/summaries/refactor-20261103.md)에서 Host/RP5 각 287개 테스트와 기존 29개 기록 재집계가 통과했고, 공식 WAV의 짧은 실제 추론도 이전 전사와 일치했다. 모델·환경·기존 기록은 유지했다.

Qwen의 전체 파일 batch 통합 시 Host/RP5는 각 300개 테스트를 통과했다. Qwen CER는 3.57%, SenseVoice는 5.16%였지만 Qwen으로 7개 발화가 악화됐다. Qwen 2T의 batch RTF는 0.6898, 파일 처리 p95는 3.400초, 추론 RSS 관측 최대는 1778.8MiB였다. 세 모델 모두 새 후보 환경에서 비교했고 기존 `.venv`와 당시 보호 대상 5,647개 파일은 유지했다.

후속 VAD·동시 실행과 자막 선택 옵션까지 Host/RP5 각 307개 테스트를 통과했다. 같은 VAD 구간의 KSS CER는 Qwen 3.70%·SenseVoice 5.56%, Qwen 기준 12개 개선·5개 악화·33개 동일이었다. 실제 동시 실행의 전사도 단독과 같았다. Qwen 2T의 구간 끝→보정 반환 p95는 KSS 3.065/3.251초·합성 3.398초, SenseVoice는 0.636/0.602초였다. Qwen 동시 모델 RSS 합 관측 최대는 약 1.98GiB였다. **Qwen은 늦게 도착하는 별도 보정 후보로 제공하며 기본 SenseVoice는 유지한다.**

새 옵션은 공식 3.5265초 WAV 1회에서 실제 후보 표시까지 확인했다. 기존 보호 대상 9,145개 파일과 Python/패키지·CPU/열 설정이 유지됐고, 새 비교/자막 원시 265개 파일을 Host에 회수해 해시를 대조했다.

## 유지하는 결정

- **자동 교체 보류:** M3-5 재생에서 KSS CER는 11.64→8.33%였지만 5개 발화가 악화됐다. 현재 Zip을 유지하고 Refine을 후보로 표시한다. 문자 범위와 실제 입력 음성 범위의 대응을 먼저 검증해야 한다.
- **원음/vad0 유지:** RMS 정규화와 일괄 문맥 확대는 개선과 악화가 함께 나타났다. 모델마다 유리한 전처리를 사후 선택하지 않는다.
- **운영 열 정책:** 기본 펌웨어 보호 아래 온도/감속을 기록한다. 저전압·계측 누락·외부 제한 실패는 거부한다. [정책](research/m3_thermal_policy.md)의 통제 비교와 운영 검사를 구분한다.
- **평가 자료:** KSS 50과 이미 본 FLEURS 100은 개발 자료다. 사용자 청취 메모 5개는 판단 어려움으로 남기고 추측 전사를 정답으로 쓰지 않는다. 보류 화자 8명/18개는 튜닝에 사용하지 않는다.
- **보존과 배포:** Host 개발→main push→RP5 pull·실측. 모델/환경/원본/과거 결과는 유지하고 새 실행 ID를 사용한다.

## 다음 순서와 완료 기준

1. **실제 사용 자료·독립 평가:** 다화자·자연 잡음·장문·숫자/외래어 조건을 사전에 고정하고 두 보정 후보의 개선/악화와 반환 지연을 확인한다. 이미 본 KSS/합성 자료의 수치를 독립 평가 성능으로 대신하지 않는다.
2. **지속 동시 부하:** Zip 1T + 선택한 보정 모델 + VAD의 더 긴 입력·반복에서 큐 적체·드롭·RSS 추세·발열을 확인한다. 이번 Qwen 2T KSS 2회를 상시 운영 안정성이나 최적 스레드의 증명으로 쓰지 않는다.
3. **보정 정책:** 음성/문자 범위와 개별 악화를 해결하는 정책을 사전에 고정하기 전까지 자동 교체는 보류한다. 자막 MVP는 Zip 원문·SenseVoice 또는 Qwen 후보를 분리 표시한다.
4. **마이크 검증:** 장치가 준비되면 지원 샘플레이트·입력 레벨·capture·드롭/백로그를 확인한다. WAV 최장 단일 입력 120.587초나 과거 8분 batch 부하를 상시 운영 합격으로 대신하지 않는다.

화면 렌더링, SSH 네트워크 도착, 음소 정렬 인식 지연, 실제 마이크, 새 MVP의 8분/상시 운영은 미검증이다. Qwen 실측은 개발 자료의 batch와 사전 고정 VAD/동시 실행 범위다. 재학습·자체 재양자화는 후속 과제로 둔다. 과거 단계별 계획은 [연구 문서 색인](research/README.md)에 보존한다.
